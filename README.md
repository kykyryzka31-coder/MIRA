# OrgStaff Mobile

Android-приложение для поиска текущего руководства российских организаций по ИНН в открытых веб-источниках.

## Возможности MVP 1.0
- Проверка контрольной суммы ИНН (10/12 цифр).
- Автоматический поиск организации и ключевых должностей через общедоступную поисковую выдачу.
- Роли: генеральный директор, директор, ректор, заместители, проректор, главный бухгалтер, главный инженер, главный конструктор.
- Статус «Подтверждено» только при совпадении ФИО/должности на двух независимых доменах.
- Карточка лица и ссылки на первоисточники.
- История запросов и избранное.
- Никакой регистрации, геолокации, контактов или доступа к файлам.

## Важно
Результаты являются справочными и зависят от индексации открытых источников. Для юридически значимой проверки используйте официальные реестры и документы организации.
